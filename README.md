# AB-650 Exam Buddy

Practice exam for Microsoft **AB-650: Administering Microsoft 365 and AI
Services**. 500 original questions over all 58 objectives in the
[study guide](https://learn.microsoft.com/credentials/certifications/resources/study-guides/ab-650),
weighted by domain, at three difficulty levels. Not real exam questions.

**Open it:** https://michaelaanraad.github.io/ab-650-Buddy/ (works offline and
on phones; progress is stored in your browser).

- Question types as on the real exam: single and multiple choice, build list
  (mostly Microsoft Graph and Exchange Online PowerShell sequences and
  admin-center steps), drag and drop, drop-down completion, yes/no, problem-
  solution series and case studies.
- Every choice has an explanation: what it is, why it is wrong here, and when
  it would be right. Every question links to its Microsoft Learn source.
- Modes: practice, exam, and exam simulation (50 questions, 100 minutes,
  review screen, sections you cannot return to).

This repository holds only the built page. The questions, tools and Claude
Code skills to build it (and other exams) live in
[MSBaseExam](https://github.com/MichaelAanraad/MSBaseExam).
